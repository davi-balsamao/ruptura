# Definir o problema — método SCQ

Você está na **etapa 1** do Problem Solving. O objetivo é produzir **uma**
Core Question: a pergunta-chave, coesa e completa, que define o problema.
A definição correta do problema determina o sucesso ou o fracasso de tudo
que vem depois — leve a sério.

## Processo

Trabalhe em três blocos, nesta ordem:

1. **Situação** — o ponto de partida, o cenário atual do cliente, aquilo que
   a audiência já sabe e aceita como verdade. Pergunte: qual é a situação
   que o cliente enfrenta hoje?

2. **Complicação** — o evento perturbador que aparece na situação e que leva
   diretamente à geração de hipóteses. Pergunte: o que mudou, o que atrapalha,
   por que isso virou um problema agora?

3. **Core Question** — a pergunta que enquadra o problema em torno da
   Situação + Complicação, de forma coesa e completa. É o que deve ser
   respondido para resolver o problema.

## Regras de qualidade da Core Question
- É **uma** pergunta, não um tema nem uma lista.
- É específica o bastante para ser respondível, mas larga o bastante para
  não excluir hipóteses legítimas.
- Deriva de forma óbvia da Situação e da Complicação — se um estranho ler só
  a Core Question, ele reconstrói o problema.
- Se a banca já deu um desafio escrito, sua Core Question deve ser uma
  versão afiada dele, não uma troca de assunto.

## ⚠️ Regra de dado (vale para TODAS as etapas)
A Situação e a Complicação se apoiam em fatos. Cada fato carrega uma tag:
`[dado: dados-case1.md#id]`, `[benchmark: fonte]` ou `[suposição]`.
Não invente número. Se não está no dossiê e você não tem fonte, é
`[suposição]` — e tem que estar marcado.

## Formato de saída
```
SITUAÇÃO: <2-3 frases, com tags de dado>
COMPLICAÇÃO: <2-3 frases, com tags de dado>
CORE QUESTION: <uma pergunta>
```

## ⚠️ Gate humano — pare aqui
Depois de produzir a Core Question, **PARE e peça aprovação humana
explícita** antes de seguir para a etapa Enquadrar. Não comece a montar
árvore nem a analisar. Uma Core Question errada aprovada por engano custa o
case inteiro; o aceite humano é o passo mais barato de toda a máquina.
